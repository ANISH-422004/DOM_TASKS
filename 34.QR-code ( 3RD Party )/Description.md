
In this task, you built a QR Code Generator using React and the react-qr-code package. The application allows users to input text, click a button, and generate a corresponding QR code. You managed the input using React’s useState hook with two state variables: Text for storing the user input and toshow for displaying the final QR code. The input field captures user text via an onChange event, and on clicking the "Generate QR" button, the HandelClick function updates the QR code and clears the input field. The QR code is dynamically displayed using the QRCode component, ensuring responsive design and proper alignment on the screen.
