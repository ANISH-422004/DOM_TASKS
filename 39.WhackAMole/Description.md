This task involved building a "Whack A Mole" game using React, where players score points by clicking on moles that randomly appear in a 3x3 grid. The game starts with an initial score of zero, and moles appear at random positions every second using setInterval and Math.random(). Players earn points by clicking on moles, handled via the Whackmole function, which updates the score and removes the mole from the grid. The game runs for 10 seconds, after which it ends by clearing the interval, resetting the grid, and displaying a "Time Up!!" message. The React state (useState) manages the score, mole positions, and game status, while useEffect handles the game’s timing and cleanup. Tailwind CSS is used for responsive and clean UI styling. This project reinforces core React concepts, including state management, event handling, and working with side effects using hooks.
